# GeoLink

GeoLink is a digital marketplace connecting customers with surveying professionals.

## Main Features
- Customer accounts
- Surveyor accounts and professional profiles
- Service requests
- Price offers and bookings
- Location-based service matching
- In-app messaging
- Ratings and reviews
- Admin dashboard
- GeoLink AI assistant

## Technology
- HTML, CSS, JavaScript
- Firebase Authentication
- Cloud Firestore
- GitHub

## Development
This repository is under active development.

The production website must remain unaffected by development changes.
